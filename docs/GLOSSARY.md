# LabSentinel · 实验室哨兵

开源的实验室安全行为智能监控系统：接入监控摄像头视频流，识别防护装备穿戴、人员身份与进出行为，异常时告警。

## Language

### 监测对象

**安全区**:
用户在摄像头画面中划定的多边形区域，进入该区域需满足防护装备要求。
_Avoid_: 报警区、警戒区、电子围栏

**防护合规**:
进入安全区的人员其防护装备（实验服等）穿戴状态是否满足该区要求。
_Avoid_: PPE 合规（可用但首次出现时应注明"防护合规（PPE Compliance）"）

**实验服**:
本项目 MVP 阶段检测的白大褂类防护服装，后续扩展护目镜、手套、口罩等。
_Avoid_: 白大褂（口语可用，文档统一用"实验服"）

**在场人数**:
某时刻某摄像头画面（或安全区）内的人数。
_Avoid_: 实时人数、人流量

**进出事件**:
一个人员目标穿越计数线或进入/离开安全区被记录为一次事实，含方向与时间。
_Avoid_: 出入记录、通行记录

### 人员与身份

**注册人员**:
已录入人脸特征并通过单独同意的人员。人脸功能关闭时此概念不生效。
_Avoid_: 白名单人员、已登记人员

**未注册人员**:
人脸功能开启时，画面中无法与任何注册人员匹配的人。
_Avoid_: 陌生人、访客（访客语义未定，暂不用）

**人脸比对**:
将检测到的人脸与注册人员特征库进行 1:N 匹配以确认身份的能力，是可整体关闭的可选模块。
_Avoid_: 人脸识别（口语可用，文档中指整套技术时用"人脸识别"，指我们的功能模块时用"人脸比对"）

**匿名计数模式**:
不提取任何人脸信息、只输出人数与进出统计的工作模式，系统的默认模式。
_Avoid_: 无脸模式、脱敏模式

### 事件与通知

**事件**:
系统检测并记录的一次事实（进出、防护不合规、人员出现等），带时间、截图等证据。
_Avoid_: 记录、日志

**告警**:
满足告警规则条件的事件被推送到通知渠道的行为。
_Avoid_: 报警、预警（"报警"易与设备报警混淆）

**告警规则**:
"区域 × 时段 × 行为类型 × 严重级别"的组合条件，决定哪些事件触发告警。
_Avoid_: 报警规则

**冷却期**:
同一摄像头同一规则触发告警后的静默时间窗，用于防止告警轰炸。
_Avoid_: 防重、去重窗口

### 部署与系统

**一体机模式**:
分析服务与 Web 客户端部署在同一台机器（如实验室的一台工作站/边缘盒子）的形态。
_Avoid_: 单机版

**客户端-服务端模式**:
分析服务部署在服务器、多端客户端远程访问的形态。
_Avoid_: CS 架构、B/S（含义偏差）

**分析管线**:
服务端从视频流取帧到输出事件的处理链路（解码→检测→跟踪→区域/规则判定→事件）。
_Avoid_: 推理链路、流水线
