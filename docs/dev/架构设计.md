两个运行时**共用同一 SQLite/契约边界**（T-332 三路径双向兼容测试）；
Rust 完全替代 Python 的 L4 **尚未开始**——Python 仍是唯一可用产品形态
（详见 `tools/README-ENGINE-BOUNDARY.md` 与 `docs/plan/status.md` §9.2）。

## 分层与模块职责

| 层 | 模块 | 职责 | 不做什么 |
|---|---|---|---|
| 入口 | `app/main.py` | create_app、lifespan、guard（Host/CSRF/读保护/审计）、WS 路由 | 不含业务逻辑 |
| API | `app/api.py` + `app/routers/*.py` | REST 路由、鉴权（管理/只读/设备三级令牌）、媒体签名、system 组件 | 不直接碰推理 |
| 采集 | `app/pipeline.py` CameraWorker | 取流、节流、调推理、产事件 | 不做告警渠道细节 |
| 推理 | `app/engine.py` Engine/PpeEngine | ONNX 会话、letterbox、解码/NMS、串行锁（DML/NPU） | 不持有业务规则 |
| 跟踪/几何/规则 | ByteTrack / `zones.py` / `rules.py` | 跨帧关联、多边形判定、规则匹配 | 不发通知 |
| 存储/统计 | `app/store.py` / `stats.py` | SQLite CRUD、日/时聚合 | — |
| 告警 | `app/alerts.py` / `ls-dispatch` | WS Hub + 8 渠道（白名单/https/禁重定向）+ SMTP | 不决定"要不要告警" |
| 配置/密钥 | `config.py` / `secretstore.py` / `fernet.rs` | pydantic-settings（LS_ 前缀）、DPAPI/Fernet 互操作 | 不硬编码路径 |
| Rust 控制面 | `engine-rs/crates/ls-server` | axum 路由 + 中间件 + 静态服务（SPA 回退/缓存策略） | 独立模式不启动分析 worker |

## 线程/进程模型（重要）

- **Python 主线程**：uvicorn/async 事件循环（API/WS）；审计写入走队列+单写线程（R2-503）。
- **CameraWorker ×N**：阻塞取流 + 同步推理；推理全局锁（DML 并发缺陷曾致死机，
  80-risk-register A1）、SMTP 线程池、视频写盘独立 recorder 线程。
- **Rust 数据面**：tokio 异步 + spawn_blocking；`probe_runtime.py --serve` 仅在便携包
  启动链中作为无控制台环境的 uvicorn 启动包装（异常落盘 `serve-boot-error.txt`）。
- **WS 投递**：worker 线程 → `run_coroutine_threadsafe` → 事件循环（线程安全桥）。

## 推理路径与后端策略（0.2.0）

1. Windows 默认 `onnxruntime==1.31.1`（CPU，与 Rust `ort` 后端同版本便于逐位对齐）；
   **可选 DML 变体** `requirements-win-dml.lock`（1.24.4，`DmlExecutionProvider`）。
2. 后端顺序可配（`LS_BACKEND_ORDER`）：directml/openvino/tensorrt/cuda/cpu 依次降级；
   `/api/system.providers` 只读透出探测结果（R2-303；Dashboard 显示 GPU 加速状态）。
3. `Engine._run()` 唯一推理入口；DML/NPU 的 `sess.run` 全进程串行（`_ACCEL_LOCK`）。
4. 实测基线（`docs/releases/perf-baseline.md`）：CPU 单路 35.8fps；DML 单路 69.43fps /
   8 路 8.06fps/路（≥ §14.3 门槛 4.5）；Rust ort 离线语料 4.0s vs tract 81.2s。
5. 黄金语料分层容差（同后端逐位、跨后端 IoU/事件一致率）见 ADR-0009。

## 事件模型（核心领域概念，术语见 docs/dev/GLOSSARY.md）

```
进入安全区事件流：
  track 进入 zone → ZoneState.entered=True
    → PPE 判定（三级证据）：no(显式 No Lab Coat) / wearing(Lab Coat≥0.2) / unknown
    → 按行为类型匹配 RuleEngine（enter / enter_no_ppe / exit / occupancy_over）
    → Store.add_event(ts, camera, type, level, track, detail, snapshot, video)
    → AlertDispatcher.dispatch（WS 实时 + 外部渠道线程池）
```

**设计原则**：证据不足判 unknown 不判违规（防误报伤信任）；冷却期按 (rule, track)
维度；occupancy_over 用 track=0。Python 与 Rust 数据面共用 proto 契约与事件口径。

## 部署拓扑（0.2.0）

- **Windows 双形态**（ADR-0010）：同一 staging 由 `build_portable.py --zip --installer`
  产出便携 zip 与 Inno Setup setup.exe；安装到 `%LOCALAPPDATA%\Programs\LabSentinel`，
  数据在 `%LOCALAPPDATA%\LabSentinel`。
- **Linux**：systemd 原生部署唯一路线（`docs/guide/部署指南-Linux.md`）；**Docker 支持已终止**
  （2026-11-11 移除 `deploy/docker/`，见 CHANGELOG）。
- Web 静态产物由服务端单端口托管（`LS_WEB_DIST`，SPA 回退 + `/assets/*` immutable 缓存）。
- 模型不随源码入库：哈希锁定于 `scripts/assets.lock.json`，CI 构建前 `fetch_assets.py` 下载。

## 架构约束（写代码前必读）

1. 推理只走 `Engine._run()`；代码审查 grep `sess.run` 即拒（Rust 走 `ls-infer` 封装）。
2. 新增 API 走 `app/routers/` 或 `ls-server/src/handlers/`，契约同步
   `docs/openapi.json` 与 `docs/dev/api-reference.md`；路由覆盖率由
   `scripts/rust_route_coverage.py` 进 CI 跟踪（≥95% L3 门槛）。
3. SQL 一律字面量 + 参数占位符（静态扫描会拦拼接）。
4. 外部 URL 必须域名白名单（防 SSRF）；回环服务请求禁用系统代理（`trust_env=False`）。
5. 每路 worker 内不得有 >100ms 阻塞操作（除推理排队）；慢操作入队/线程池。
6. 前端不引入重型图表/UI 库（bundle 预算 gzip ≤100KB）。
7. 安全判定以实际监听地址为准（`settings.host` 单一来源 + 运行时 `scope["server"]` 兜底）；
   非回环无令牌一律拒绝启动（R2-102）。
