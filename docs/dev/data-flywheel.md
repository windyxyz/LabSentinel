# 90 · 数据飞轮规划（模型持续变强的机制）

> v0.1（2026-10-26）· 核心命题：公开数据集只能冷启动。让模型真正贴合用户实验室的唯一路径是**"真实画面 → 标注 → 训练 → 评估"的可持续闭环**。本文定义这个闭环的每一步。

## 飞轮总览

```
① 真实画面采集（用户实验室摄像头/离线视频）
        ↓ 抽帧（去重、分场景、均衡时段）
② 半自动预标注（当前模型出框 → 人工只做修正）
        ↓ 导出 YOLO 格式 + 人工复核
③ 合入训练集（datasets/lab-ppe-real/，与公开数据按比例混合）
        ↓ 限线程过夜训练 + test split 评估
④ 部署新模型（classes.txt 同步）→ 真实场景再评估
        ↓ 误报/漏报回流 ②
```

## ① 采集与抽帧

**输入来源**（优先级排序）：
1. 用户实验室真实摄像头的录像（**必须取得现场人员知情同意/按机构规定**——这是合规前置，写进部署文档）
2. 用户提供的公开素材（B 站等，仅限内部评测，不得入库/发布）
3. 部署方自愿回传的脱敏截图（未来社区版功能，默认关闭）

**抽帧规则**（工具：`tools/frame_sampler.py`，待写）：
- 每段视频每 2 秒抽 1 帧 → 场景变化检测（frame diff）去重 → 每段保留 100-300 帧
- 均衡覆盖：不同时段（上午/下午/夜间）、不同机位、有无人员、穿/未穿
- 输出：`datasets/lab-ppe-real/raw/` + 索引清单（来源、时间、帧号）

## ② 半自动预标注（关键提效环节）

**流程**：
1. 运行 `tools/preannotate.py`（待写）：当前模型对每帧预出框 → 写 YOLO txt（lab coat / no lab coat / person）
2. 人工修正：**Roboflow 网页标注**（用户已有账号）上传图片+预标注，只拖拽修正——比从零画框快 5-10 倍
   - 备选：LabelImg/CVAT（离线，无账号依赖）
3. 导出 YOLO 格式（Roboflow 免费额度内）

**标注规范（统一语义，避免标签漂移）**：
- **Lab Coat**：人身上可见的白色实验服主体（含袖子），遮挡 >70% 不标
- **No Lab Coat**：清晰可见的便服/短袖/未穿者躯干区域（与 Person 框同范围）
- 同一人同时被标 Lab Coat 与 Person 不冲突（两框并存，语义不同）
- 侧身/背影：只要能判断是否白大褂就标；判断不了的帧弃用
- 边缘截断 >50% 的人不标
- 标注歧义帧单独放 `ambiguous/` 不进训练（宁缺毋滥）

**每轮数量目标**：首轮 300-500 帧（覆盖 5-10 个机位/时段）即可显著改善；后续每轮 200 帧增量。

## ③ 混合训练策略

- 配比：真实数据 : 公开数据 = 1 : 3~4（真实数据珍贵但域正确，公开数据保泛化、防遗忘）
- 训练：限线程（`torch.set_num_threads(6)`）+ fraction 抽样 + 早停；CPU 过夜约 4-6h
- **每次实验记录**：数据版本、配比、超参、逐类 AP —— 写进 `runs/<name>/README.md`（工具链任务 06 固化）
- 数据版本化：`datasets/lab-ppe-real/v1/`、`v2/`…（图片+标签+data.yaml+来源清单）

## ④ 评估与回流

**评估集**：始终保留一个**从未参与训练的真实画面 test 集**（≥50 帧，含穿/未穿/无人），每版模型跑一次 → 生成对比表（检出率、误报率、置信度分布）。

**上线门槛**（建议）：
- Lab Coat AP50 ≥0.90 且真实 test 集检出率 ≥80%
- No Lab Coat 误报（把穿的人报成未穿）在 test 集 ≤5%
- 部署后 24h 告警抽查：人工确认准确率 ≥80%

**回流**：运营期误报/漏报事件 → 截图进 `标注池`（Web 事件页"误报"按钮已规划于 M2C 事件闭环）→ 每月批次回流 ②。

## 数据集开源发布（社区贡献飞轮）

- 每轮真实数据（**脱敏后**：模糊人脸、移除可识别信息、取得授权）可发布为 `labsentinel-labcoat-vN`（CC BY 4.0 或 MIT），附标注规范与来源声明
- 这是项目对社区的回馈，也是吸引其他实验室贡献数据的招牌（"你的 300 张标注，换全行业的模型进步"）

## 节奏建议

- **首轮**（v2 效果若仍不达标即启动）：300-500 帧，1-2 天标注，1 晚训练 → v3 模型
- **常规**：每 1-2 月一轮增量 200 帧
- **每次发布**：公开模型评估表 + （可选）更新开源数据集版本
