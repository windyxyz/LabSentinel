# Release Notes · LabSentinel v0.4.0

> **未签名预览版**——安装时 SmartScreen 可能提示，请核对 `SHA256SUMS-rust.txt`。
> 发行形态：Rust 单二进制 zip + Inno Setup 7 安装包。

## Highlights

### 模型管理：实验服模型可关闭、可替换
- 「设置 → 模型与检测 → 本地模型」新增开关：**启用实验服检测**（关闭后仅人员检测）。
- **上传替换模型**：选择自定义 `.onnx` 即上传并立即启用（保存在
  `%LOCALAPPDATA%\LabSentinel\data\models\ppe-custom.onnx`），运行中相机自动重启。
- **恢复随包模型**：一键回到安装包自带的实验服权重。
- 状态页展示模型来源（随包 / 自定义 / 环境变量）、真实 SHA256 与大小。

### API 多接入：保存多个上游，随时切换
- 可以保存多套 API 服务（公司 GPT、本机 Ollama、Gemini…），在列表里**随时切换
  启用**；切换后跟随全局策略的相机即时生效。
- 每个档案独立保存：协议、地址、模型、密钥（加密落盘、接口只回 `***`）、超时、
  远程合规确认；旧的单配置会自动显示为「默认服务」，首次保存即迁移。

### 连通性检测 + 自动获取模型
- 「测试连通性」实时探测上游：OpenAI 兼容 `/v1/models`、Ollama `/api/tags`、
  Gemini `/v1beta/models`，返回耗时与可用模型数，失败时给出 HTTP 状态与原因。
- **「获取模型」自动列出上游模型**并填入下拉，不用再手抄模型名。
- 「测试判定」用一张真实图片走完整判定链（需先保存并启用档案、模式为仅 API/协作）。

### 同版本随附
- 实验服模型随包发布（0.3.1 起），安装即有「人员 + 实验服检测」。
- 仪表盘版本号显示实际版本（修复此前恒显示 0.2.0）。
- 左侧主导航吸顶；安装包完成页排版修复；卸载清理 `versions\`/旧目录/Prefetch，
  用户数据默认保留（交互卸载可选删除，静默卸载 `/REMOVEDATA=1`）。

## 升级说明

- 直接覆盖安装，数据目录 `%LOCALAPPDATA%\LabSentinel\data` 不受影响。
- 旧版 `.env` 的 `LS_VLM_*` 仍作为兜底；网页保存档案后以档案为准。
