# 00 · 项目愿景

> 状态：v0.2（2026-10-25）· 项目定名 **LabSentinel / 实验室哨兵**

## 一句话定位

一个**开源、可本地部署、隐私可控**的实验室安全行为智能监控系统：接入现有监控摄像头，自动识别"进入安全区是否穿戴实验服"等防护合规行为、统计进出人数与时间，并在异常时实时告警。

## 要解决的问题

- 实验室安全管理制度要求穿戴防护装备、限制进入时段/人数，但**靠人工盯屏幕和巡查不可持续**。
- 市面商业方案（智慧实验室 AI 监控类产品）**闭源、按路收费、数据常需上云**，中小实验室和课题组用不起、不敢用。
- 已有开源 NVR（如 Frigate）面向家庭安防，**没有"防护合规、实验室规则"这类领域语义**。

## 目标用户

1. **实验室安全管理员**（主用户）：高校院系/研究所的实验室安全负责人。
2. **实验室管理员**：课题组/教学实验室的日常管理者。
3. 部署者可能是用户本人（自己的实验室），也可能是有一定动手能力的 IT 人员。

## 核心价值主张（差异化）

| 维度 | 商业方案 | 本项目 |
|---|---|---|
| 成本 | 按路/按年授权，整体方案万元级 | 开源免费，复用现有摄像头 |
| 数据 | 常需上云 | 全本地，人脸等敏感数据不出内网 |
| 定制 | 厂商封闭 | 规则、区域、模型均可自定义，可自训模型 |
| 透明 | 黑盒 | 全链路开源，可审计 |

## 非目标（v1 明确不做）

- 门禁/闸机等硬件联动控制
- 周界防护、车牌识别等通用安防能力
- 云端 SaaS 托管服务（多租户运营）
- 替代商业 NVR 的完整录像管理（只做事件相关的短视频证据）

## 合规立场（设计原则，详见 20-research/00-synthesis.md 合规节）

人脸属于敏感个人信息。系统按"最小化 + 可关闭"设计：

1. **匿名计数模式为默认**：不开人脸功能也能完成人数统计、防护合规检测。
2. 人脸比对模块**默认关闭**，开启需管理员操作且面向注册人员取得单独同意。
3. 现场需配合显著提示标识（部署文档提供模板）。
4. 人脸不作为任何验证的唯一方式；特征数据仅存本地。
5. 系统内置合规自查清单，写入部署文档。

## 成功标准

- **M0（技术验证）**：1 路 1080p RTSP 流，实时（≥5 FPS 分析帧率）检测人员+实验服，纯 CPU 可跑通，WebRTC 延迟可接受。
- **M1（MVP）**：Docker 一键部署，Web 端配置安全区与规则，白大褂不合规事件实时告警（应用内+1 个外部渠道），事件可回查。
- **M2+**：人脸比对（默认关）、多路扩展、移动端。

## 开源协议

**已决策（2026-10-25）**：代码仓库 AGPL-3.0 + Ultralytics YOLO 生态；模型与数据集不直接入库，由安装脚本下载并附协议声明（Roboflow CC 数据集与模型协议各异，避免再分发风险）。见 [adr/0001](./adr/0001-agpl-and-ultralytics.md)。
