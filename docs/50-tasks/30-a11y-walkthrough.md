# 任务 30 · Web 无障碍与一致性走查（先读本目录 README.md）

## 目标（检查 + 小修复）

1. **无障碍走查**（playwright + 人工规则）：
   - 键盘导航：Tab 顺序合理、所有交互元素可聚焦、抽屉/弹层 Esc 可关且焦点还原、焦点环可见（theme.css 已定义 focus-visible）
   - 语义：表格有表头、按钮有可读文本（图标按钮需 aria-label——检查导航/播放/关闭按钮）、图片有 alt
   - 对比度：正文/次要文字/徽章在当前深色主题下达到 WCAG AA（可用 playwright 注入简单对比度脚本或人工取色；列出不达标项）
   - 表单：input 有关联 label 或 aria-label（摄像头表单/安全区命名/令牌输入）
2. **UI 一致性走查**：
   - 页面标题层级（h3 使用一致）、卡片间距、按钮尺寸（32px 标准 vs 例外清单）
   - 列表空态文案统一（"暂无事件"等）
   - 所有页面在浅色/深色主题下无硬编码色残留（grep 组件内 `#` 十六进制色值，报告清单）
3. **修复**：以上发现的问题直接修复（视图组件 `<style scoped>` 或模板属性），并在执行报告列出"发现→修复"对照表；**不改 theme.css/style.css/App.vue**（主线专属，如发现全局问题只写报告）

## 约束

- 需服务与前端运行；训练中 CPU 高时用静态检查项跳过动态项并标注
- 不改业务逻辑，只改语义/可访问性属性与 scoped 样式
