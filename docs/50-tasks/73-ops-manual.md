# 任务 73 · 运维手册（日常使用/排障/升级/备份）

> 背景：现有文档偏"怎么装/怎么开发"，缺少面向部署单位日常运维的一本通：每天看什么、出问题先查什么、
> 升级怎么回滚、数据怎么备份、告警不响怎么定位。本任务写 `docs/运维手册.md`，作为交付后的操作入口。

## 目标

新增 `docs/运维手册.md`（中文，面向非开发者），至少包含：

1. **10 分钟上手**：安装 → 首次启动（`LabSentinel.exe`）→ 打开页面 → 添加摄像头 → 画安全区 →
   加规则 → 测试告警 → 确认事件；每步给截图位置或界面路径（不要求新截图，引用现有 `docs/assets/`）。
2. **每日/每周巡检清单**：Dashboard 指标（今日事件/未处置/磁盘）、摄像头状态（fps/画面停滞/重连）、
   告警投递失败、日志错误、磁盘余量；给出"正常/需处理"的判定阈值（引用配置项，不编数字）。
3. **启动/停止/自启**：EXE / `启动.bat` / `停止.bat` / 安装器快捷方式；单实例与端口漂移
   （8000→8100）说明；开机自启的开关方法；服务未启动时页面表现。
4. **摄像头排障**：RTSP 地址模板、子码流、H.264/H.265、USB 设备选择（任务 60 的下拉）、
   索引变化、隐私挡板、被会议软件占用、`last_error`/重连次数怎么读（任务 65）。
5. **告警排障**：`/api/alerts/status` 看渠道 configured；一键自测；失败重发；通用 Webhook 验签
   （任务 67）；邮件 SMTP 常见错误；"未配置渠道不产生失败记录"的口径。
6. **日志与诊断**：日志路径（任务 61）、轮转文件、`/api/diagnostics/summary`、
   `scripts/collect_diagnostics.py` 生成脱敏包；报障时应提供哪些信息（版本/request_id/诊断包）。
7. **备份/恢复/迁移**：`scripts/backup_data.py backup/verify/restore`（任务 62）、数据目录位置、
   WAL 文件说明（任务 64）、升级前先备份、恢复后首次启动自动迁移（任务 69）。
8. **升级/回滚**：便携包覆盖升级（数据外置）、安装器覆盖升级、旧版本回滚（保留上一版 zip）、
   数据库迁移失败时用备份恢复。
9. **容量与性能**：分析帧率 `LS_ANALYSIS_FPS`、多路建议（引用 57 实测，若 57 未完成则写"待补"）、
   保留天数/磁盘下限、何时该加机器/降路数。
10. **安全与合规**：管理令牌、只读账号、反向代理 HTTPS、人脸功能默认关闭与同意留痕、
    日志/诊断包脱敏边界。
11. **故障速查表**：症状（打不开页面/摄像头 error/无事件/告警不发/磁盘满/升级后旧页面）→
    先查什么 → 处理命令；每条链接到对应章节/FAQ。
12. **发布后 24h 观察清单**：与 `docs/摄像头24h验收清单.md` 对齐，但面向运维（看哪些指标、何时回滚）。

## 约束

- **只写文档**，不改代码；所有命令必须与仓库现状一致（写前核对 `scripts/`、`config.py`、端点）；
- 不编造性能数字：57/61/62 未完成时写"见对应任务报告/待补"，完成后回填；
- 不复制粘贴大段现有文档，用链接 + 一页速查；
- 面向非开发者：少用术语，命令给完整可复制形式（Windows 路径）。

## 验收标准

- 命令逐条核对：在源码根能执行的至少实跑 `--help`/只读命令；涉及写操作的命令标注"会改数据"；

- 报告附链接检查结果与命令核对表。
