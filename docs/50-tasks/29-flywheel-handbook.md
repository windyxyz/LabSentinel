# 任务 29 · 数据飞轮实操手册（用户/社区版）——先读本目录 README.md

> 依据：docs/90-data-flywheel.md（规划版）。本任务产出面向部署者/贡献者的 step-by-step 操作手册。

## 目标（纯文档）

新建 `docs/标注与模型迭代手册.md`（中文，面向"会用电脑但不会训练模型"的实验室管理员）：

1. **什么时候需要做**：v2 模型在你的实验室画面效果不好（漏检/误报）时的判断标准（给 3 个自查例子）
2. **准备**（一步步）：同意/合规提示（现场标识模板引用）→ 采集视频（现有摄像头录像导出方式：海康/大华/NVR 通用说明）→ 抽帧命令（tools/frame_sampler.py 用法 + 参数建议）→ 预标注（tools/preannotate.py 用法）
3. **标注**（Roboflow 网页，含免费额度说明）：创建项目 → 上传图片+预标注 → 修正要点（引用 90 飞轮标注规范：Lab Coat/No Lab Coat/遮挡/侧身/截断规则）→ 导出 YOLO 格式
4. **训练**（两种方式）：
   - 本机 CPU：工具链命令（tools/train_ppe.py 参数、限线程、预计耗时公式"张数÷6000×小时"）
   - 云 GPU（可选）：把数据集打包上传到 Colab/云平台的简要步骤（不绑定具体平台，写通用流程）
5. **评估与接入**：test 集评估（eval_report）→ 导出 ONNX（export_onnx）→ classes.txt → 按 docs/45-model-onboarding.md 接入与灰度
6. **FAQ**：样本要多少（首轮 300-500 帧起效）、要多久、效果不好怎么办（继续采样/换机位/检查标注一致性）、数据隐私（脱敏、授权、不得上传他人实验室数据到公共服务）
7. **贡献回社区**（可选）：脱敏后数据集按 CC BY 4.0 发布流程（引用 90 飞轮第 5 节）

## 约束

- 不承诺具体精度提升数字；给区间与条件
