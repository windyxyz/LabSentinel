2. **重负载一次只跑一个**；训练由主线巡检按《训练安全规程》负责，**你不需要也不要启动训练**。
3. **端口**：8000（服务端）/5173（vite）归主线预览；你测试用 FastAPI TestClient 或 8001。
4. `supervision==0.25.1` 钉死；`onnxruntime` 与 `onnxruntime-directml` 不可同装；Git Bash curl 发中文 JSON 会损坏（用 python httpx）。
