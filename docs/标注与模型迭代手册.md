# 标注与模型迭代手册（数据飞轮实操版）

> 面向读者：实验室管理员——会用电脑、不需要会训练模型。
> 目标：当 LabSentinel 在**你的**实验室画面上效果不理想时，用"抽帧 → 标注 → 训练 → 接入"四步让模型学会你的场景。
> 配套：规划原理见 [90-data-flywheel.md](90-data-flywheel.md)；模型上线流程见 [45-model-onboarding.md](45-model-onboarding.md)。
>
> **环境口径**：本手册命令里的 `D:/LabSentinel/m0-venv` 是**训练专用环境**（装了 ultralytics/torch，
> 服务端不用它）。服务端运行/测试用项目内 `.venv`（`python scripts\deploy.py install` 创建）；
> 仅"抽帧/预标注"两步若不想动训练环境，也可用 `.venv` 执行（有 cv2 与 onnxruntime），
> 训练/评估/导出必须用 m0-venv。便携包用户不需要任何 venv。

## 0. 什么时候需要做这一套

先自查（满足任意一条就值得做一轮）：

1. **漏检**：有人进入安全区但经常没有告警（回看录像对比事件列表，漏掉超过三成）。
2. **误报**：频繁对"其实穿了白大褂"的人告警，或对家具/管路/仪器产生持续误报。
3. **换了环境**：摄像头挪了位置、换了机位、加了新监控点（模型没见过这个角度）。

> 如果只是个别阈值问题（比如告警太敏感），先调 `.env` 里的 `LS_PPE_CONF` / `LS_PPE_WEARING_CONF` 再决定要不要走本手册。

## 1. 准备

### 1.1 合规先行（必做）

- 在采集范围张贴**显著提示标识**（模板见部署指南合规章节）。
- 训练用画面**优先选择无正脸**的机位或时段；用于社区发布的素材必须按第 6 节脱敏。
- 依据《人脸识别技术应用安全管理办法》与 PIPL 的完整清单见部署指南合规自查。

### 1.2 采集视频

| 来源 | 导出方式 |
|---|---|
| 海康/大华 NVR | Web 管理页 → 回放 → 选时段 → 导出为 MP4（H.264） |
| 海康/大华摄像机直连 | 同上，或用厂商工具 ivms-4200 / SmartPSS 批量导出 |
| 通用 RTSP | 用 ffmpeg 录制：`ffmpeg -rtsp_transport tcp -i "rtsp://用户:密码@IP:554/子码流" -c copy out.mp4` |
| 手机 | "IP 摄像头"类 App 的录像文件，拷到电脑即可 |

建议每个机位覆盖：有人的时段、无人时段、穿/未穿都出现。

### 1.3 抽帧（tools/frame_sampler.py）

```bash
# 单视频：每 2 秒抽 1 帧，静态画面自动去重，最多 300 帧
D:/LabSentinel/m0-venv/Scripts/python.exe tools/frame_sampler.py --video D:/录像/实验室.mp4 --out Resources/datasets/frames

# 多个视频一次抽（--video-dir 填目录）
D:/LabSentinel/m0-venv/Scripts/python.exe tools/frame_sampler.py --video-dir D:/录像 --out Resources/datasets/frames --interval 2.0 --max 300
```

参数建议：机位少就 `--interval 1.0` 抽密一点；画面长时间静止的调低 `--diff-thresh`（默认 8.0，越小保留越多）。
产出：`Resources/datasets/frames/` 下的 JPG + `manifest.csv`（来源与时间索引）。

**首轮数量目标：300–500 帧**（覆盖 5–10 个机位/时段即可明显见效，见 FAQ）。

### 1.4 预标注（tools/preannotate.py，模型先替你画一遍）

```bash
D:/LabSentinel/m0-venv/Scripts/python.exe tools/preannotate.py --images Resources/datasets/frames --out Resources/datasets/labels --model m0-spike/yolo11n_ppe.onnx --classes-file m0-spike/yolo11n_ppe.classes.txt
```

产出：每张图一个同名 YOLO txt（空图也有空文件）+ `Resources/datasets/labels/preview/` 带框目检图。
**预标注只是起点**——先翻一遍 preview，把明显框错的（管子被框成人等）心里有数，下一步人工修正。

## 2. 标注（Roboflow 网页，免费额度足够首轮）

1. 注册/登录 [app.roboflow.com](https://app.roboflow.com) → Create New Project → Object Detection，类别贴 11 类词表（`m0-spike/yolo11n_ppe.classes.txt`）。
2. Upload → **Upload Images with Annotations** → 把 `Resources/datasets/frames` 的图片与 `Resources/datasets/labels` 的同名 txt 一起拖入（自动配对）。
3. 人工修正要点（与 90-data-flywheel.md 标注规范一致）：
   - **Lab Coat**：人身上可见的白大褂主体（含袖子）；遮挡超过 70% 不标。
   - **No Lab Coat**：清晰可见的便服躯干区域（与 Person 框同范围）。
   - 同一人同时有 Lab Coat 框与 Person 框是**正常的**（两个语义）。
   - 侧身/背影：能判断穿没穿就标；判断不了的帧移入 `ambiguous/` 不进训练。
   - 画面边缘截断超过一半的人不标。
4. Generate 版本（Preprocessing 保持 "Resize 640×640 - Stretch"）→ Export → **YOLO v11 格式**，下载解压。

## 3. 训练

### 方式 A：本机 CPU（推荐首轮）

```bash
D:/LabSentinel/m0-venv/Scripts/python.exe tools/train_ppe.py --data <Roboflow导出的data.yaml路径> --epochs 24 --batch 8 --workers 2 --name ppe_real_v1
```

- 预计耗时 ≈ 图片张数 ÷ 6000 小时（5000 图约 50 分钟/轮 × 24 轮，早停会更快）；
  建议**过夜跑**，训练期间不要在这台电脑上做视频剪辑、多路推理等重活。
- 前置条件与看门狗见 训练安全规程（历史任务包已清理）（限线程、单任务）。

### 方式 B：云 GPU（可选，数据量大时）

通用流程（不绑定平台）：把导出的 YOLO 数据集（含 data.yaml）打包 zip → 上传到任意支持 ultralytics 的环境（如 Colab）→ `pip install ultralytics` → `yolo detect train data=<yaml> model=yolo11n.pt epochs=24 imgsz=640` → 下载 `best.pt`。**注意：上传前必须完成脱敏与授权确认（见第 6 节）。**

## 4. 评估与接入

```bash
# 1) test 集评估（与旧模型同口径对比，结果追加进 历史模型评估记录）
D:/LabSentinel/m0-venv/Scripts/python.exe tools/eval_report.py --model runs/detect/ppe_real_v1/weights/best.pt --data <data.yaml> --classes <类名文件> --split test --label "real-v1"
# 2) 导出 ONNX
D:/LabSentinel/m0-venv/Scripts/python.exe tools/export_onnx.py --weights runs/detect/ppe_real_v1/weights/best.pt
# 3) 词表文件：把训练 data.yaml 的 names 存为 m0-spike/yolo11n_ppe.classes.txt（一行一类，顺序=输出顺序）
```

然后按 [45-model-onboarding.md](45-model-onboarding.md) 接入（改 `.env` 指向新 ONNX → 重启服务端 → 用"效果演示"或真实画面确认）。
灰度建议：先只开一路摄像头用新模型观察 24 小时，再全量切换。

## 5. FAQ

- **样本要多少？** 首轮 300–500 帧即可起效（覆盖多机位多时段）；之后每轮增量 200 帧即可维持。
- **要花多久？** 标注 300 帧约 1–2 小时（有预标注时是"修正"不是"从零画"）；本机训练一晚；全流程 2–3 天。
- **效果还是不好？** 按顺序排查：① 标注一致性（Lab Coat 与 No Lab Coat 是否混标）→ ② 机位覆盖（新增角度的帧）→ ③ 继续按飞轮迭代（每轮增量标注）。
- **数据隐私？** 训练用素材留在本机；上传任何云服务前必须脱敏（模糊人脸）并取得授权；**不得**把他人实验室的数据上传到公共服务；社区发布走第 6 节流程。
- **误报样本有捷径吗？** 有：Web 端把事件标"误报"，截图会自动进 `server/data/annotation_pool/`，直接作为下一轮标注池（tools/preannotate.py 的 --images 指向它）。

## 6. 贡献回社区（可选）

脱敏确认完成后，用 `tools/export_dataset.py --version N` 打包数据版本（自动生成来源清单与脱敏确认清单），按 [90-data-flywheel.md](90-data-flywheel.md) 第 5 节以 CC BY 4.0 发布——你的 300 张标注，换全行业模型进步。
