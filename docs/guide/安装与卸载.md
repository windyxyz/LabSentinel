# 安装、升级与卸载（Rust 单包 · 0.3.0 起）

> 适用产物：`labsentinel-rust-<版本>-<日期>.zip`（GitHub Releases）。
> 包内自带检测模型、ffmpeg、onnxruntime 与前端，**不需要安装 Python / Node / 数据库**。
> 旧版 `LabSentinel-setup-*.exe` / `LabSentinel-portable-*.zip`（嵌入式 Python）已随
> ADR-0011 过渡期结束退役；仍可从旧版本 Release 下载，但不再更新。

## 安装

1. 把 zip 解压到任意可写目录（下称“安装根”，例如 `D:\Apps\LabSentinel`）。
   **不要解压到 `C:\Program Files`**（普通用户无写权限）。
2. 双击安装根里的 **`LabSentinel.bat`**：
   - 首次启动自动创建数据目录并按需初始化数据库；
   - 约 2–5 秒后浏览器自动打开控制台（默认 <http://127.0.0.1:8000>）；
   - 首次打开会进入三步引导（接入摄像头 → 选择模型 → 通知方式），全部可在网页内完成。
3. 需要开机自启：`Win+R` → `shell:startup` → 把 `LabSentinel.bat` 的快捷方式放进启动目录。

### 默认端口与局域网访问

| 需求 | 做法 |
|---|---|
| 换端口 | 启动前设 `LS_PORT=8080`（或在 `LabSentinel.bat` 里加一行 `set LS_PORT=8080`） |
| 局域网访问 | 设 `LS_HOST=0.0.0.0` **且必须设** `LS_ADMIN_TOKEN=<足够长的随机串>`，否则拒绝启动 |
| 只读令牌 | 可选 `LS_READ_TOKEN` + `LS_AUTH_READ_PROTECTED=1` |

## 数据位置（升级/卸载都不丢）

| 内容 | 默认路径 |
|---|---|
| 数据库 / 截图 / 视频 / 标注池 / 缩略图 | `%LOCALAPPDATA%\LabSentinel\data\` |
| 模型（可选覆盖） | 安装根 `models\`，或网页「模型管理」选择的文件 |
| 日志 | 控制台输出；需要留存时把 `LabSentinel.bat` 的输出重定向到文件 |

> WAL：`data\` 下的 `labsentinel.db-wal` / `-shm` 属正常伴随文件，**不要手删**。
> 备份/迁移请用网页「设置 → 数据管理 → 导出配置」，或调用
> `POST /api/backups/run`（SQLite 一致快照）；只拷 `.db` 会丢 WAL 中未合并的数据。

## 升级（保留数据，可回滚）

```bat
rem 1) 先停止服务：网页「设置 → 服务控制 → 停止服务」，或结束 labsentinel-server.exe
rem 2) 归档当前版本（安装根内会生成 versions\<版本>\，自动排除 data/）
cd /d D:\Apps\LabSentinel
labsentinel-server.exe --archive .

rem 3) 解压新 zip 覆盖到同一目录（保留 data\ 与 versions\）
rem 4) 再次双击 LabSentinel.bat
```

- 归档目录只含程序文件；数据库/截图/视频仍在 `%LOCALAPPDATA%\LabSentinel\data`，不受升级影响。
- 数据库结构变更由程序启动时自动向前兼容迁移（只加列/表）。
- 升级后若启动异常，可回滚：

```bat
labsentinel-server.exe --rollback .
```

回滚会选 `versions\` 中除 `current.txt` 记录外的最新一版覆盖安装根，数据目录不动。

## 卸载

1. 停止服务（网页「设置 → 服务控制」或结束进程）。
2. 删除安装根目录。
3. 如需彻底清除数据：删除 `%LOCALAPPDATA%\LabSentinel\`。
4. 如设置过开机自启：从 `shell:startup` 删除快捷方式。

## 校验下载

每个 Release 附带 `SHA256SUMS-rust.txt`：

```powershell
Get-FileHash .\labsentinel-rust-<版本>-<日期>.zip -Algorithm SHA256
# 与 SHA256SUMS-rust.txt 中的值逐字对比
```

未签名预览版可能触发 SmartScreen「未知发布者」提示；校验哈希后再决定是否继续。

## 发布产物说明

- 构建：`python scripts/prepare_rust_assets.py` → `python scripts/build_rust.py --strict --zip`
  （CI 由 `.github/workflows/release.yml` 自动执行，产物含 zip + `SHA256SUMS-rust.txt`）。
- 冒烟：`python scripts/smoke_rust.py --zip <zip>`（解包 → 启动 → 就绪 → API/前端断言 → 停止）。
- 包内清单：`labsentinel-server.exe`、`LabSentinel.bat`、`VERSION`、`web\`、`models\`、
  `tools\ffmpeg\`、`tools\onnxruntime\`、`tools\go2rtc.exe`、`NOTICE.txt`、`README.txt`。

## 常见问题

- **双击 bat 后浏览器没弹出**：看命令行窗口是否有报错；确认 8000 端口未被占用
  （`netstat -ano | findstr :8000`），或设 `LS_PORT` 换端口后重试。
- **局域网打不开**：确认 `LS_HOST=0.0.0.0`、已设 `LS_ADMIN_TOKEN`，并在防火墙放行该端口。
- **没有检测结果**：确认「模型管理」已选中模型；图片文件夹源还要在「安全区配置」画好区域与规则。
- **插件启动失败**：插件若声明 `{python}` 解释器，需要系统已安装 Python 并加入 PATH
  （便携包不再内置 Python 运行时）。
- **杀毒软件告警**：先校验 SHA256；仍拦截时把安装根与数据目录加入排除项
  （见 [杀毒软件误报说明](杀毒软件误报说明.md)）。
- **无网络**：安装与运行均不需要联网；仅外部 VLM、告警推送、版本检查需要出网。
