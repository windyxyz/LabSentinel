# 安装、升级与卸载（0.2.0 · Rust 单包）

> 适用产物（GitHub Releases）：
> - **`LabSentinel-setup-<版本>.exe`**——Windows 安装器（推荐，双击安装）；
> - `labsentinel-rust-<版本>-<日期>.zip`——便携包（解压即用）。
>
> 包内自带检测模型、ffmpeg/ffprobe、onnxruntime 与前端，**不需要安装 Python / Node / 数据库**。
> 旧版 Python 形态的 `LabSentinel-setup-*.exe` / `LabSentinel-portable-*.zip` 已随
> ADR-0011 过渡期结束退役；仍可从旧版本 Release 下载，但不再更新。

## 安装（方式 A：setup.exe，推荐）

1. 下载 `LabSentinel-setup-<版本>.exe`，双击运行（未签名预览版可能触发 SmartScreen，
   先按下方「校验下载」核对哈希）。
2. 选择语言（简体中文 / English）→ 选择安装模式：
   - **仅为我安装**（默认，无需管理员）：`%LOCALAPPDATA%\Programs\LabSentinel`；
   - **为所有用户安装**（需要管理员）：`%ProgramFiles%\LabSentinel`。
3. 完成页默认勾选「开始菜单快捷方式」「桌面快捷方式」，可取消；安装器最后会真实启动
   新版本做一次健康检查（`--selftest-http`），通过后才算完成。
4. 双击桌面/开始菜单的 **LabSentinel** 快捷方式：约 2–5 秒后浏览器自动打开控制台
   （默认 <http://127.0.0.1:8000>），首次进入三步引导（接入摄像头 → 选择模型 → 通知方式）。

## 安装（方式 B：便携 zip）

1. 把 zip 解压到任意可写目录（下称“安装根”，例如 `D:\Apps\LabSentinel`）。
   **不要解压到 `C:\Program Files`**（普通用户无写权限）。
2. 双击安装根里的 **`LabSentinel.bat`**，其余同上。
3. 需要开机自启：`Win+R` → `shell:startup` → 把 `LabSentinel.bat` 的快捷方式放进启动目录。

### 默认端口与局域网访问

| 需求 | 做法 |
|---|---|
| 换端口 | 启动前设 `LS_PORT=8080`（安装版可在快捷方式目标前加 `set LS_PORT=8080 &&`，便携版在 `LabSentinel.bat` 里加一行） |
| 局域网访问 | 设 `LS_HOST=0.0.0.0` **且必须设** `LS_ADMIN_TOKEN=<足够长的随机串>`，否则拒绝启动 |
| 只读令牌 | 可选 `LS_READ_TOKEN` + `LS_AUTH_READ_PROTECTED=1` |

## 数据位置（升级/卸载都不丢）

| 内容 | 默认路径 |
|---|---|
| 数据库 / 截图 / 视频 / 标注池 / 缩略图 | `%LOCALAPPDATA%\LabSentinel\data\` |
| 版本归档（升级回滚点） | 安装根 `versions\<版本>\` |
| 模型（可选覆盖） | 安装根 `models\`，或网页「模型管理」选择的文件 |
| 日志 | 控制台输出；需要留存时把 `LabSentinel.bat` 的输出重定向到文件 |

> WAL：`data\` 下的 `labsentinel.db-wal` / `-shm` 属正常伴随文件，**不要手删**。
> 备份/迁移请用网页「设置 → 数据管理 → 导出配置」，或调用
> `POST /api/backups/run`（SQLite 一致快照）；只拷 `.db` 会丢 WAL 中未合并的数据。

## 升级（保留数据，可回滚）

### 安装版（setup.exe）

直接运行新版本 `LabSentinel-setup-<新版本>.exe` 覆盖安装：

- 安装器在复制文件前自动执行 `labsentinel-server --archive`，把旧版归档到
  `versions\<旧版本>\`（自动排除 `data\`）；
- 安装完成后自动 `--selftest-http` 探活；失败时按提示手工执行 `--rollback`；
- 数据目录（`%LOCALAPPDATA%\LabSentinel\data`）不受影响。

### 便携版（zip）

```bat
rem 1) 先停止服务：网页「设置 → 服务控制 → 停止服务」，或结束 labsentinel-server.exe
rem 2) 归档当前版本（安装根内会生成 versions\<版本>\，自动排除 data/）
cd /d D:\Apps\LabSentinel
labsentinel-server.exe --archive .

rem 3) 解压新 zip 覆盖到同一目录（保留 data\ 与 versions\）
rem 4) 再次双击 LabSentinel.bat
```

### 回滚

```bat
cd /d <安装根>
labsentinel-server.exe --rollback .
```

回滚会选 `versions\` 中除 `current.txt` 记录外的最新一版覆盖安装根，数据目录不动。

## 卸载

### 安装版（setup.exe）

- 设置 → 应用 → 安装的应用 → LabSentinel → 卸载（或开始菜单「Uninstall LabSentinel」）；
  卸载器会先结束常驻的 `labsentinel-server.exe` 再删除文件。
- 数据目录 `%LOCALAPPDATA%\LabSentinel\` 与安装根 `versions\` **不随卸载删除**；
  需要彻底清除时手工删除该目录。

### 便携版（zip）

1. 停止服务（网页「设置 → 服务控制」或结束进程）。
2. 删除安装根目录。
3. 如需彻底清除数据：删除 `%LOCALAPPDATA%\LabSentinel\`。
4. 如设置过开机自启：从 `shell:startup` 删除快捷方式。

## 校验下载

每个 Release 附带 `SHA256SUMS-rust.txt`，同时列出 zip 与 setup.exe：

```powershell
Get-FileHash .\LabSentinel-setup-<版本>.exe -Algorithm SHA256
Get-FileHash .\labsentinel-rust-<版本>-<日期>.zip -Algorithm SHA256
# 与 SHA256SUMS-rust.txt 中的值逐字对比
```

未签名预览版可能触发 SmartScreen「未知发布者」提示；校验哈希后再决定是否继续。

## 发布产物说明

- 构建（CI `.github/workflows/release.yml` 自动执行）：
  1. `python scripts/prepare_rust_assets.py`——准备模型/ffmpeg/onnxruntime（哈希锁）；
  2. `python scripts/build_rust.py --strict --zip`——编 Rust 单二进制并出
     `labsentinel-rust-<版本>-<日期>.zip`；
  3. `python scripts/build_setup_exe.py`——ISCC（Inno Setup 7）把同一 staging 树
     编成 `LabSentinel-setup-<版本>.exe`；
  4. `SHA256SUMS-rust.txt` 同时包含两个产物。
- 冒烟：`python scripts/smoke_rust.py --zip <zip>`（解包 → 启动 → 就绪 → API/前端断言 → 停止）。
- 包内清单：`labsentinel-server.exe`、`LabSentinel.bat`、`VERSION`、`web\`、`models\`、
  `tools\ffmpeg\`、`tools\onnxruntime\`、`tools\go2rtc.exe`、`NOTICE.txt`、`README.txt`。

## 常见问题

- **双击快捷方式后浏览器没弹出**：看命令行窗口是否有报错；确认 8000 端口未被占用
  （`netstat -ano | findstr :8000`），或设 `LS_PORT` 换端口后重试。
- **局域网打不开**：确认 `LS_HOST=0.0.0.0`、已设 `LS_ADMIN_TOKEN`，并在防火墙放行该端口。
- **没有检测结果**：确认「模型管理」已选中模型；图片文件夹源还要在「安全区配置」画好区域与规则。
- **插件启动失败**：插件若声明 `{python}` 解释器，需要系统已安装 Python 并加入 PATH
  （发行包不内置 Python 运行时）。
- **杀毒软件告警**：先校验 SHA256；仍拦截时把安装根与数据目录加入排除项
  （见 [杀毒软件误报说明](杀毒软件误报说明.md)）。
- **无网络**：安装与运行均不需要联网；仅外部 VLM、告警推送、版本检查需要出网。
