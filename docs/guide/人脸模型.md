# 人脸模型与人员录入

在「设置 → 人脸识别」可以关闭功能、使用本地 YuNet + SFace 或使用 CompreFace API。模型连接设置与启停保存后生效。默认关闭。访问控制仍由网页密码、会话或现有 API 凭据承担。

## 配置

- 本地模式可在网页下载两份经 SHA-256 校验的 ONNX 文件，约 39 MB。下载完成后可离线录入和试识别。推理沿用系统的 DirectML 优先、失败回落 CPU 设置。模型面板显示实际运行设备。手动部署可以将官方同版本文件放入数据目录的 `models/face/`。 [YuNet 模型与 MIT 许可](https://github.com/opencv/opencv_zoo/tree/48b10fa505aeb51fbd127fc60a5c660040e823b7/models/face_detection_yunet) · [SFace 模型与 Apache 2.0 许可](https://github.com/opencv/opencv_zoo/tree/48b10fa505aeb51fbd127fc60a5c660040e823b7/models/face_recognition_sface)
- API 支持保存多个 CompreFace 档案，分别启停、测试连接、调整阈值和选择当前档案。输入服务地址或以 `/api/v1` 结尾的 API 地址。远程服务使用 HTTPS，同一台机器可以使用 HTTP。API 密钥加密保存在数据目录。
- 保留现有 `LS_FACE_ENABLED`、`LS_COMPREFACE_URL`、`LS_COMPREFACE_API_KEY` 等环境配置的首次读取。网页首次保存后以网页配置为准。为旧名单重新录入并登记同意后，应用才会给出人员匹配。

## 录入与撤回

1. 取得本人同意。在浏览器里拍摄或上传 1–5 张单人 JPEG／PNG。每张上限 5 MB。正面和略微转头的照片都有助于核对识别质量。
2. 填写姓名并录入，另拍一张试识别。本地只保存加密模板。CompreFace 样本使用独立编号发送，源图保存由 CompreFace 的 `save_images_to_db` 设置控制。 [CompreFace 样本和 API 文档](https://github.com/exadel-inc/CompreFace/blob/master/docs/Rest-API-description.md#managing-subject-examples)
3. 人员库显示同意时间和到期日，新录入默认保留 90 天。撤回及到期立即退出匹配，事件中的人员结果随之停止显示。远程不可达时待删除状态会留下，恢复后可以重试，也会自动重试。
4. 如需事件身份辅助，在相机权限中开启对应选项。允许 API 后，所选服务会收到相机事件中的人物上半部区域。无匹配、多人、模型关闭和 API 故障均使用原有事件流程。匹配结果只在管理界面的事件详情展示。

## 验收

在可执行 Rust 测试程序的 Windows 环境中，使用发布包的 ORT、两份经校验的 ONNX 和授权照片。设置 `LS_FACE_TEST_ASSETS` 为包含两份 ONNX 以及 `sample-0.jpg`、`sample-1.jpg`、`sample-2.jpg` 的目录。前两张应为同一人，第三张应为不同人。 [OpenCV 的公开示例](https://github.com/opencv/opencv_zoo/blob/48b10fa505aeb51fbd127fc60a5c660040e823b7/models/face_recognition_sface/README.md#example-outputs)

```powershell
cargo +stable-x86_64-pc-windows-gnu test -p ls-server local_face_model_matches_reference_pairs -- --ignored --nocapture
$env:LS_FACE_TEST_DEVICE = 'directml'
cargo +stable-x86_64-pc-windows-gnu test -p ls-server local_face_model_matches_reference_pairs -- --ignored --nocapture
```

每组记录相似度、是否匹配、实际推理设备及耗时。用来自拟部署场景的授权样本另测不同光线、脸部大小、角度、遮挡和多人画面下的误接受率与误拒绝率。CompreFace 联测覆盖断网时的未知结果和撤回后的远程删除。
