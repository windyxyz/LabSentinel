# 多路性能验收

基准使用随包 FFmpeg、go2rtc、ONNX Runtime、YOLO11n 和实验服模型。视频源是 1920×1080、12 FPS 的 H.264 RTSP。分析保持 5 FPS，工作帧缩放为 1280×720。合成片段按 4 秒分段，依次是空场、有人、低光、远景和运动测试图。

## 同参数运行

在 `engine-rs` 下按 [Windows 构建配方](../../AGENTS.md#4-本机构建与测试配方windows-中文路径必读) 配置工具链。将 `$stage` 指向已解包的 Windows 发行目录，将 `$results` 指向结果目录。

```powershell
$env:LS_INSTALL_DIR = $stage
$env:LS_FFMPEG = Join-Path $stage 'tools\ffmpeg\ffmpeg.exe'
$env:ORT_DYLIB_PATH = Join-Path $stage 'onnxruntime.dll'
$env:LS_PPE_MODEL = Join-Path $stage 'models\yolo11n_ppe.onnx'
$env:LS_INFER_BACKEND = 'ort'
$env:LS_BENCH_EP = 'cpu'
$env:LS_BENCH_CAMERAS = '4'
$env:LS_BENCH_SECONDS = '30'
$env:LS_BENCH_REPORT = Join-Path $results 'cpu-4.json'
$env:LS_BENCH_PID_FILE = Join-Path $results 'cpu-4.pid'
cargo +stable-x86_64-pc-windows-gnu test --release -p ls-server --all-features tests::performance::windows_rtsp_benchmark -- --ignored --nocapture
```

完整短测用 `cpu` 和 `dml` 各运行 1、4、9 路。为每组指定独立的报告和 PID 文件。用 `LS_BENCH_OUTAGE=1` 加入断流与恢复。在另一个 PowerShell 窗口用以下命令同步采样进程树。

```powershell
..\scripts\sample_benchmark.ps1 -PidFile $env:LS_BENCH_PID_FILE -OutputCsv (Join-Path $results 'cpu-4-resources.csv')
```

识别质量使用同一视频的确定性离线回放，分别记录各场景有人判定和 PPE 状态。

```powershell
$env:LS_BENCH_REPORT = Join-Path $results 'scene-truth.json'
cargo +stable-x86_64-pc-windows-gnu test --release -p ls-server --all-features tests::performance::windows_scene_truth_replay -- --ignored --nocapture
```

报告包含每路有效分析 FPS、模型实际运行次数、DirectML 调用、重连和分阶段 p50／p95／p99。`analysis_after_read_ms` 从完成读取原始帧到规则分析完成。`read_wait_ms` 包含等待 FFmpeg 提供下一帧的时间。各路延迟窗口最多保留最近 1,200 帧，总计数覆盖测量全程。CSV 聚合基准及其子进程的 CPU、工作集、私有内存和可用的 GPU 引擎计数器。

## 2026-11-23 分项结果

Windows 11 专业工作站版 26300，AMD Ryzen AI 9 H 365，Radeon 880M 驱动 32.0.32015.16001。ffprobe 核验测试源为 20.000 秒、240 帧、1920×1080 H.264。

使用 go2rtc 提供同一隔离 RTSP 源，FFmpeg 客户端各解码 10 秒媒体时间并缩放，输出交给空复用器。下表耗时含握手及首帧等待。

| 并发 | FFmpeg 正常退出 | 每路输出帧 | 实际耗时范围 |
| --- | --- | --- | --- |
| 1 路 | 1/1 | 46 | 11.910 秒 |
| 4 路 | 4/4 | 46 | 11.822–11.894 秒 |
| 9 路 | 9/9 | 46–50 | 11.772–11.883 秒 |

完整 Rust 流程的 Release 依赖编译程序、Debug 基准程序和独立模型工具的 NumPy 模块均遇到 Windows 应用控制 4551。CPU／DirectML 整链数据、识别质量、4 路对比和 9 路长跑为空缺，待在可执行发行构建的 Windows 环境用同一场景补齐。
