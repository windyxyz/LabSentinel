# LabSentinel 快速开始

> **只想马上用？** 下载 `labsentinel-rust-<版本>-<日期>.zip` → 解压 → 双击
> `LabSentinel.bat`，浏览器自动打开控制台。无需 Python/Node/数据库，详见
> [安装与卸载](安装与卸载.md)。本文件补充源码运行与开发调试路径。

实验室安全行为监控系统：接入摄像头/视频文件/图片文件夹 → AI 识别未穿戴防护用品
（白大褂、手套、护目镜等）→ 实时画面 + 事件告警 + 报表导出。

## 环境要求（发布包）

- Windows 10/11 x64（Linux 可源码构建运行）
- 无需管理员权限，无需联网（仅外部 VLM/告警推送/版本检查需要出网）
- 显卡：无独显也可运行（CPU 推理）；包内为 CPU 版 onnxruntime

## 三步跑起来（发布包）

1. 解压到任意可写目录（路径可含中文，建议避免空格/特殊符号）
2. 双击 `LabSentinel.bat`
3. 浏览器自动打开 <http://127.0.0.1:8000>；首次进入按向导完成摄像头/模型/通知配置

之后每次双击 `LabSentinel.bat` 即可；停止服务用网页「设置 → 服务控制」。

## 源码运行（开发者）

```bash
# 前端构建
cd web && npm ci && npm run build && cd ..

# 资产（模型/ffmpeg/onnxruntime；已存在则跳过；Python 仅作构建工具）
python scripts/prepare_rust_assets.py

# Rust 服务端（自动打开浏览器）
cd engine-rs && cargo run -p ls-server -- --launch
```

- 开发热更新：`cd web && npm run dev`（Vite 5173，API 代理到 8000）
- 打包：`python scripts/build_rust.py --strict --zip` → `Resources/dist/labsentinel-rust-*.zip`
- 一键启停（go2rtc + Rust API + Vite）：`scripts/start-all.bat` / `scripts/stop-all.bat`

## 首次配置

- **摄像头**：「摄像头」页添加 RTSP/视频文件/USB/图片文件夹，必要时先到「安全区配置」
  画区域、加规则，再回来启动
- **模型**：「模型管理」选择包内模型 / 自备 ONNX / 外部联网模型（按摄像头切换）
- **通知**：「告警配置」保存企业微信/钉钉/飞书/Server酱/PushPlus/Qmsg/邮件渠道，保存即生效
- **令牌/导入导出/插件/服务控制**：均在「设置」页（左侧分类 + 搜索）

## 常见问题

- **端口被占用**：设 `LS_PORT=8080` 后重启；局域网访问需 `LS_HOST=0.0.0.0` + `LS_ADMIN_TOKEN`
- **没有检测结果**：确认「模型管理」已选模型；文件夹源需先画区域/加规则
- **实时画面黑屏**：确认 `tools/go2rtc.exe` 存在并已启动（发布包自带，可参考部署指南）
- **告警推送**：渠道参数在网页端填写（密钥加密存储），不需要改配置文件
- **人脸比对**：合规敏感功能，默认关闭；开启前必读 [部署指南](部署指南.md) 合规章节

## 目录速览

```

scripts/       构建/验收/开发脚本（Python 仅作开发工具）
tools/         训练/量化/标注工具链 + go2rtc + ffmpeg
docs/          使用/开发/发布/决策文档
Resources/     效果演示/插件示例/数据集/分发包
```
