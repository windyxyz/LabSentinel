# LabSentinel 快速开始（demo 包 / 源码部署）

> **只想马上用？** 优先用**便携包**（`LabSentinel-portable-*.zip`，双击 `安装.bat` + 桌面快捷方式，无需 Python/Node、无需联网）——见根 [README.md](../../README.md) 与 [docs/guide/安装与卸载.md](安装与卸载.md)。本文件讲的是 demo 包（自动装环境）与源码部署两条路径，适合开发者或需要改代码的场景。

实验室安全行为监控系统：接入摄像头/视频文件/图片文件夹 → AI 识别未穿戴防护用品（白大褂、手套、护目镜等）→ 实时画面 + 事件告警 + 报表导出。

## 环境要求

- Windows 10/11 x64
- 能上网（首次部署自动下载依赖：先扫本机已有组件，缺失才下载，且国内镜像/CDN 失败会自动切官方源）
- Python 3.10+（必需：首次部署用它创建 venv；没装时启动器会给出安装指引）
- 无需管理员权限（启动器不再请求 UAC 提权，避免新机上提权后丢失 Python 的 PATH）
- 显卡：无独显也可运行（自动回退 CPU；有 DX12 显卡自动启用 DirectML 加速）

## 三步跑起来

1. **解压本包到任意目录**（路径可以含中文，但建议避免空格和特殊符号）
2. **双击 `一键启动.bat`**
3. 等待自动部署完成（首次 5-10 分钟；先复用本机已装的 Python 包/Node/ffmpeg，缺的才从国内镜像下载，镜像不通自动切官方源），浏览器会自动打开控制面板

之后每次双击 `一键启动.bat`，检测到服务在运行就直接打开面板；没运行就自动拉起。

## 演示内容（开箱即用）

包内已预置 4 路演示摄像头（实验室行走、防护穿戴两组视频循环播放）和对应的检测区域/规则。服务启动后：

- **仪表盘**：实时事件流、今日统计
- **摄像头**：查看实时画面（WebRTC）、启停分析
- **事件**：截图/视频证据、标记误报、导出
- **报表**：日/周统计、CSV/PDF 导出、证据包
- **图片识别**：外部软件持续截图的目录 → 自动筛选关键图片/违规图片并汇报（见 [docs/68](图片文件夹接入.md)）

演示视频里人员进入"试剂区"且未穿白大褂时会触发 L3 违规事件。

## 启动器菜单

| 选项 | 作用 |
|---|---|
| [1]-[4] | 打开面板 / API 文档 / 健康检查 / 日志目录 |
| [5] / [6] | 重启服务 / 停止服务 |
| [7] 重新部署（保留数据） | 重装运行环境，事件与摄像头配置不动 |
| [8] 重新部署（清空数据） | 重装环境并重置为演示初始状态 |
| [9] 一键卸载 | 停服务并删除环境组件（数据改名备份保留） |
| [0] | 退出脚本，服务继续后台运行 |

## 手动部署（不用启动器）

```bat
python scripts\deploy.py check      环境体检
python scripts\deploy.py install    自动部署
python scripts\deploy.py uninstall  卸载
scripts\start-all.bat               启动三组件
python scripts\doctor.py            自检（模型/Web/DB/端口/磁盘）
scripts\stop-all.bat                停止
```

## 常见问题

- **双击 bat 闪退**：右键"在终端中打开"后运行 `一键启动.bat` 看具体报错；多数是没装 Python，按提示装 3.10+ 并勾选 Add to PATH
- **提示"未找到 Python"但明明装了**：启动器会先试 `py -3` 再试 `python`；若都失败，说明安装时没勾选 Add to PATH，重装或手动把 Python 目录加入 PATH
- **下载慢/某个源连不上**：部署引擎会先扫本机已有组件（venv/Node/ffmpeg/OpenH264），缺失才下载；pip/npm/ffmpeg/Node 均配了国内镜像，失败会自动切换官方源，窗口里会打印当前用的源
- **端口被占用**：8000/5173/1984 被其他程序占用时对应组件起不来，关掉占用程序或改 `LS_PORT` 类配置（见 server/.env.example）
- **实时画面黑屏**：需要 ffmpeg（部署脚本优先复用本机，找不到才下载到 tools/ffmpeg）；重启服务即可
- **告警推送**：企业微信/钉钉/飞书/Server酱/PushPlus/QQ( Qmsg)/邮件 均支持，配置方法见 `server/.env.example` 注释与 `docs/guide/部署指南.md`
- **人脸比对**：合规敏感功能，默认关闭；开启前必读 `docs/guide/部署指南.md` 合规章节
