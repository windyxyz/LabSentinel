## 轨迹对齐第二轮（2026-11-07，检测逐位一致后的 ByteTrack 语义修复）

检测层逐位一致后，用 `export_real_track_vector.py`（Python supervision 真值）+
`ls-analyzer --golden --dets-from --dump-tracks/--dump-states` 回放对比，逐帧定位并
修复 **4 个 ls-track 移植语义差异**：

1. **Kalman 精度**：supervision KF 全程 numpy float64，Rust 误用 f32——真实序列
   300+ 帧累积 2px 级误差。Kalman 全面提升 f64（Mat8/mean/covariance）。
2. **remove_duplicate_tracks 阈值语义写反**：Python `iou_distance < 0.15` 才算重复
   （IoU > 0.85），Rust 误写成 IoU ≥ 0.15 就去重——拥挤场景大量轨迹被误删。
3. **空帧语义**：Python `_analyze` 空检测帧不调 ByteTrack（track 状态冻结），
   Rust 每帧都调——空帧会推进 frame_id、累积 lost 超时。
4. **输出语义**：supervision `update_with_detections` 返回**输入检测框原样** ×
   tracker_id（IoU ≥ 0.5 匹配回填、未关联检测丢弃、新建 track 首帧
   is_activated=False 不输出）——Rust 误返回 Kalman 反算框且不过滤。
   pipeline 的 zone anchor / PPE 匹配随之对齐到检测框原样。

**修复后轨迹 diff**（真实 322 帧）：first divergence frame 4 → **52**，差异帧
214 → **183**。事件 104 条（vs Python 113）。剩余分歧为 supervision 语义的
长尾（fuse_score 权重、iou 距离实现细节等），诊断工具链已完备，按同样方法继续。

## 轨迹对齐第三轮（2026-11-07，收敛至逐帧一致 322/322）

回放测试（`ls-analyzer` tests::replay_real_track_vector，消费 real-big.json 的
检测+轨迹+**KF 状态快照**三层真值）逐层定位，本轮修掉 **3 个根因**：

1. **KF 预测 Q 矩阵速度项误带 10×**（`ls-track/kalman.rs`）：supervision
   `predict()` 的 `std_vel = std_weight_velocity·h`（**无** 10×；10× 仅存在于
   `initiate()`），Rust 误从 initiate 复制了系数——速度方差放大 100 倍、速度增益
   被压小、预测框滞后漂移（f52 实测预测框差 12px → fused cost 0.805>0.8 关联失败）。
   位置后验恰好不受影响（位置 Q 正确），故此前"均值链对、协方差链断"。
   用 numpy 逐位复刻 supervision KF（喂同一 2dp 舍入检测）对照定位：
   f4 后验位置方差逐位一致、速度方差 377.68 vs 843.08 → 唯一自由度即 Q 系数。
2. **removed 列表滞后一帧的账本 quirk**（supervision core.py 末段）：
   `lost = sub(lost, removed_OLD)` 用的是**上一帧** removed 列表，本帧 Step 5
   超时标记的轨仍滞留 lost/pool 一帧（下帧才被 sub 出，期间可被 re_activate）。
   Rust 原当帧立即清出——差一帧的重配窗口。Rust 按同序复刻（滞留 + 每帧重收
   超时轨入 removed_NOW + 用上一帧 removed 列表做 sub）。
3. **末段 match-back 缺失**（`update_with_detections` 最后一道重指派）：Python
   输出不是关联轮次的记账，而是**独立的回配**——全部输入检测 × 激活轨迹（后验框）
   的 f64 IoU → LAP(thr 0.5) → 命中取 external_id、未命中丢弃。f81 实测：后验框
   被 Kalman 拉大时回配**否决**轮次配对（IoU 0.448<0.5 被钳制拒收）。Rust 删除
   det_assign 记账、实现独立回配；KM 泛型化（f32=轮次路径 / f64=回配路径），IoU
   统一为 f64 框→f64 运算→f32 降级（与 numpy dtype 流逐位一致）。

**结果**：diff_frames 183 → **0**（322/322 帧轨迹逐帧一致，KF 状态 322 帧逐帧
一致 ±0.15px）。回放测试移除 `#[ignore]` 转正为回归门禁（ls-track 任何语义/
精度回归会直接爆掉）。Rust workspace 49 tests 全绿（clippy -D warnings + fmt 净）。
