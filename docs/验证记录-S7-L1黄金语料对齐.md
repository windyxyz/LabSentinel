## 大语料扩展实测（2026-11-06 补）

| 语料 | 分析帧 | Python 事件 | Rust 事件 | track-agnostic 一致率 |
|---|---|---|---|---|

| 前三语料合计 | 165 | 18 | 18 | 94.4% |

诊断（tools/detect_compare.py 思路 + --dump-dets）：
- 检测总量 Python 380 框 vs Rust 384 框，仅 **8/322 帧（2.5%）数量差 ±1**（双侧互有，
  NMS/阈值边界的浮点临界对）；NMS 已对齐（同分稳定序 + 分母 +1e-9）后差异不变；
- 检测层小差在**多人遮挡场景被 ByteTrack 关联放大**：Kalman 预测的浮点累积差 →
  遮挡帧的匹配选择不同 → 轨迹合并/分裂路径分叉 → ID 重映射失效（T-324 的
  "轨迹划分一致"前提是输入检测序列完全一致）。

**定位（2026-11-06 深夜修正）**：检测框 IoU ≥ 0.99（§13.8 L1 检测标准）已达标。
事件级差距有两个真实根因，均已定位并部分修复：

1. **ffmpeg fps 滤镜 vs cv2 顺序解码的帧错位**（主因）：`fps=30` 滤镜按输出时间基
   重排/丢帧（VFR、首帧 PTS≠0 的视频错位 1-2 帧），与 cv2 纯顺序解码抽到不同帧 →
   轨迹划分完全分叉。**已修复**：ls-ingest 支持 `analysis_fps=0`（仅 scale，纯顺序
   解码），golden 模式改用该模式自行按 step 抽帧。修复后大语料
   **track-agnostic 一致率 63.7% → 85.0%**（96/113，时间槽覆盖 46/50）。
2. **ts 语义残差**（次因）：Python POS_MSEC 为容器 PTS（VFR 视频帧间隔不均匀），
   Rust golden 的 `帧序×(1/fps)` 是理想化计算——VFR 段落错位可达 ±0.3s（>0.21s
   容差）。后续：Rust golden 解析 ffprobe 逐帧 PTS（ffprobe -show_frames）与
   Python 逐位对齐。
3. 推理引擎差（tract vs ORT）实测**不是**主因：ORT-CPU 与 tract 结果完全一致；
   Python CPU EP 与 DML EP 输出也一致（DML 差异此前被抽帧错位掩盖）。

**ort 后端集成（T-328 前置，已完成）**：ort 2.0.0-rc.15 绑定层纯 Rust（rc.10+ 无
bindgen/libclang），windows-gnu 构建成功；`ls-infer feature=ort`（load-dynamic，
`ORT_DYLIB_PATH` 指向 onnxruntime.dll，实测 ORT 1.31.1）+ `LS_INFER_BACKEND=ort`
运行时切换；`ls-infer` 双后端（tract/ort）共存、YoloModel::load 按参数/env 选择；
ls-ingest 支持 analysis_fps=0 顺序解码模式。Rust 52 tests 全绿。

**预处理逐位对齐（2026-11-07，最终定位）**：`resize_u8_linear_cv2` 复刻 cv2
INTER_LINEAR 的 uint8 定点实现（2048 系数 + `>>22`、round-half-even、边界截断），
逐像素验证：**黄金语料路径 1280x720→640x360（2 倍缩小）逐位一致**；非整倍缩小
（609x342）max diff=1（conf 影响 ~1e-5，远低于 1e-3 口径）；上采样不在检测路径。
同输入推理输出对比（40 帧）：**框 IoU≥0.998 但 conf 差最大 0.0166**——根因确认为
**ORT 版本演进差**：Python 生产 venv = onnxruntime 1.24.4，ort 2.0.0-rc.15 硬性
要求 ≥1.31.x（旧 rc.10-rc.14 需要 bindgen/libclang，本机不可用；rc.15 实测拒绝
加载 1.24.4 DLL）。事件一致率（track-agnostic）85% 的剩余差距即此版本差的
conf 边界效应（A 多 7 组 enter/exit 对 = 轨迹分裂点不同）。

**方案 A 已执行（2026-11-07，维护者拍板）**：requirements.in 的 win32 分支改为
`onnxruntime==1.31.1`（directml 包无 1.31 wheel），requirements-win.lock 重生成，

**升级后的关键实测**：① Python 1.24.4 与 1.31.1 输出完全同构（113 事件同 track）——
**排除 ORT 版本演进差假设**；② 两级 cv2 缩放对齐后（ffmpeg 纯解码 + resize_u8
