# 所有 AI 分析在服务端，客户端为瘦客户端

---
status: accepted
date: 2026-10-25
---

视频源是服务端接入的 RTSP 摄像头，若把分析放到客户端，每个端都要实现一遍取流、解码、推理，且五端（Web/安卓/iOS/鸿蒙/小程序）的端侧推理能力参差（小程序几乎不可行）。因此决定：**分析管线全部在服务端（一体机或服务器），客户端只做实时观看、告警接收、事件查询与配置**，零 AI 依赖。立项时设想的"客户端本地模型或 API 接云端"降级为后期实验特性（如手机扫码式巡检），不进核心架构。

## Consequences

- 客户端跨端迁移只剩 UI 层工作，多端成本大幅下降（这正是能承诺 uni-app x 五端覆盖的前提）。
- 服务端成为性能瓶颈：多路扩展能力完全取决于部署机（用小型模型 + 子码流分析缓解，M0 实测写死硬件需求）。
